# Statistical tests: theory reference and decision rules

> Generated by `scripts/make_test_reference.py` from `ds_agent/stats/tests.py` and `ds_agent/stats/panels.py`. Do not edit by hand — edit the catalogue and re-run the script.

Every analysis conclusion in this agent carries a table of the tests it ran, each row with the statistic, the p-value, the decision and the citation. This document is the theory behind those rows: what the null hypothesis is, why the statistic has the form it has, which assumptions must hold, and where the method comes from.

## 1. How to read a test result

| Concept | Meaning | Common mistake |
| --- | --- | --- |
| H0 | The default claim: no difference, no effect, no association, the series is stationary | Stating H0 after seeing the data |
| p-value | P(data at least this extreme \| H0 is true) | Reading it as P(H0 is true) |
| α | The false-positive rate you accept before looking | Changing α after seeing p |
| Decision | p < α → reject H0; p ≥ α → fail to reject (never "accept") | Treating non-significance as proof of no effect |
| Power | 1 − β: the chance of detecting a real effect of a given size | Running an underpowered test and reading the null as a finding |
| Effect size | How large the difference is, in metric units or standardised | Reporting "significant" for an effect too small to act on |
| Multiple testing | Many tests inflate false positives; BH-FDR controls the share | Reading 20 raw p-values and shipping the smallest |
| Equivalence | "No meaningful difference" requires TOST, not a failed test | Turning p = 0.21 into "no impact" |

### 正态性 · Normality

#### Shapiro-Wilk 正态性检验 / Shapiro-Wilk normality test

- **原假设 / H0**: 样本来自正态分布 / the sample is drawn from a normal distribution
- **统计量 / Statistic**: `W = (Σ a_i x_(i))² / Σ (x_i − x̄)²`
- **前提 / Assumptions**: 观测独立同分布；样本量建议 3–5000（更大样本改用 D'Agostino K²） / i.i.d. observations; n between 3 and 5,000 (use D'Agostino K² above that)
- **适用 / When to use**: 小样本下判断 t / F / ANOVA 的正态前提是否成立 / deciding whether t / F / ANOVA assumptions hold on small samples
- **判定 / Decision**: p < α → 显著偏离正态：改用秩检验（Mann-Whitney / Wilcoxon）或先做变换 / significant departure from normality: switch to a rank test or transform the data; otherwise → 未发现偏离正态的证据，正态理论检验可用 / no evidence against normality; normal-theory tests are admissible
- **参考 / Reference**: Shapiro, S. S. & Wilk, M. B. (1965). An analysis of variance test for normality. Biometrika 52(3/4), 591-611.（Shapiro & Wilk (1965)）

#### D'Agostino-Pearson K² 正态性检验 / D'Agostino-Pearson K² normality test

- **原假设 / H0**: 样本来自正态分布（偏度=0 且峰度=3） / the sample is normal (skewness 0 and kurtosis 3)
- **统计量 / Statistic**: `K² = Z_skew² + Z_kurt² ~ χ²(2)`
- **前提 / Assumptions**: 观测独立；样本量建议 ≥ 20 / independent observations; n ≥ 20
- **适用 / When to use**: 大样本（>5000）下的正态性检验，Shapiro-Wilk 的替代 / normality testing on large samples (>5,000), where Shapiro-Wilk is unreliable
- **判定 / Decision**: p < α → 偏度或峰度显著异常：大样本下即便轻微偏离也会显著，应结合 QQ 图判断 / skewness or kurtosis is off: at large n even trivial departures reject — read it with a QQ plot; otherwise → 未发现偏度/峰度异常，正态近似可用 / no skewness or kurtosis anomaly; the normal approximation holds
- **参考 / Reference**: D'Agostino, R. B., Belanger, A. & D'Agostino, R. B. (1990). A suggestion for using powerful and informative tests of normality. The American Statistician 44(4), 316-321.（D'Agostino et al. (1990)）

#### Jarque-Bera 正态性检验 / Jarque-Bera normality test

- **原假设 / H0**: 样本来自正态分布 / the sample is drawn from a normal distribution
- **统计量 / Statistic**: `JB = n/6 · (S² + (K − 3)²/4) ~ χ²(2)`
- **前提 / Assumptions**: 观测独立；对尾部厚度敏感 / independent observations; sensitive to tail thickness
- **适用 / When to use**: 回归残差、大样本指标的快速正态性体检 / quick normality check on regression residuals and large samples
- **判定 / Decision**: p < α → 残差非正态：区间估计与 t 检验在大样本下仍近似有效，但预测区间需谨慎 / non-normal residuals: t tests stay approximately valid at large n, but prediction intervals need care; otherwise → 残差与正态相容 / residuals are compatible with normality
- **参考 / Reference**: Jarque, C. M. & Bera, A. K. (1980). Efficient tests for normality, homoscedasticity and serial independence of regression residuals. Economics Letters 6(3), 255-259.（Jarque & Bera (1980)）

#### Anderson-Darling 正态性检验 / Anderson-Darling normality test

- **原假设 / H0**: 样本来自正态分布 / the sample is drawn from a normal distribution
- **统计量 / Statistic**: `A² = −n − (1/n) Σ (2i−1)[ln F(x_(i)) + ln(1 − F(x_(n+1−i)))]`
- **前提 / Assumptions**: 观测独立；对尾部偏离最敏感 / independent observations; most sensitive in the tails
- **适用 / When to use**: 关心尾部（极端值、风控、金额）时替代 Shapiro-Wilk / tail-sensitive normality checks (risk, revenue outliers) instead of Shapiro-Wilk
- **判定 / Decision**: p < α → 尾部偏离正态：极端值推断不可依赖正态假设 / tails depart from normality: do not rely on normal-theory tail inference; otherwise → 尾部与正态相容 / tails are compatible with normality
- **参考 / Reference**: Anderson, T. W. & Darling, D. A. (1954). A test of goodness of fit. JASA 49(268), 765-769.（Anderson & Darling (1954)）


### 方差 · Variance

#### Levene / Brown-Forsythe 方差齐性检验 / Levene / Brown-Forsythe equal-variance test

- **原假设 / H0**: 各组方差相等 / the groups share a common variance
- **统计量 / Statistic**: `W = [(N−k)/(k−1)] · Σ n_i (Z̄_i − Z̄)² / Σ Σ (Z_ij − Z̄_i)²,  Z = |x − median_i|`
- **前提 / Assumptions**: 观测独立；中位数中心化后对非正态稳健 / independent observations; median-centring makes it robust to non-normality
- **适用 / When to use**: 选择 Welch t（不齐）还是 Student t（齐），以及 ANOVA 的前提检查 / choosing Welch vs Student t, and as an ANOVA prerequisite
- **判定 / Decision**: p < α → 方差不齐：用 Welch t / 稳健标准误，不要用合并方差的 Student t / unequal variances: use Welch t or robust SEs, not pooled-variance Student t; otherwise → 方差可比：合并方差与 t 检验的前提成立 / variances are comparable: pooled-variance tests are admissible
- **参考 / Reference**: Brown, M. B. & Forsythe, A. B. (1974). Robust tests for the equality of variances. JASA 69(346), 364-367.（Brown & Forsythe (1974)）

#### Bartlett 方差齐性检验 / Bartlett equal-variance test

- **原假设 / H0**: 各组方差相等（数据正态） / the groups share a common variance (normal data)
- **统计量 / Statistic**: `χ² = [(N−k) ln s_p² − Σ (n_i−1) ln s_i²] / C,  C = 1 + (Σ 1/(n_i−1) − 1/(N−k))/(3(k−1))`
- **前提 / Assumptions**: 各组正态；对非正态极敏感 / normality within groups; very sensitive to departures
- **适用 / When to use**: 正态数据下方差齐性的最强检验（功效高于 Levene） / the most powerful equal-variance test when the data really are normal
- **判定 / Decision**: p < α → 方差不齐（或数据非正态导致误拒）：以 Levene 结果为准 / variances differ (or non-normality drove the rejection): trust Levene instead; otherwise → 方差齐性成立 / equal variances are not rejected
- **参考 / Reference**: Bartlett, M. S. (1937). Properties of sufficiency and statistical tests. Proceedings of the Royal Society A 160(901), 268-282.（Bartlett (1937)）


### 位置 · Location

#### Student t 检验（合并方差） / Student t-test (pooled variance)

- **原假设 / H0**: 两组均值相等，且两组方差相等 / equal means, assuming equal variances
- **统计量 / Statistic**: `t = (ȳ₂ − ȳ₁) / (s_p √(1/n₁ + 1/n₂)),  df = n₁ + n₂ − 2`
- **前提 / Assumptions**: 独立样本、近似正态、方差齐性 / independent samples, approximate normality, equal variances
- **适用 / When to use**: 方差齐且样本量接近时的经典两样本检验 / the classic two-sample test when variances and sizes are comparable
- **判定 / Decision**: p < α → 两组均值差异显著 / the group means differ significantly; otherwise → 未发现均值差异 / no mean difference detected
- **参考 / Reference**: Student (Gosset, W. S.) (1908). The probable error of a mean. Biometrika 6(1), 1-25.（Student (1908)）

#### Welch t 检验（不等方差） / Welch t-test (unequal variances)

- **原假设 / H0**: 两组均值相等 / the two group means are equal
- **统计量 / Statistic**: `t = (ȳ₂ − ȳ₁) / √(s₁²/n₁ + s₂²/n₂),  df ≈ Welch-Satterthwaite`
- **前提 / Assumptions**: 独立样本、近似正态；不要求方差齐性 / independent samples, approximate normality; equal variances NOT required
- **适用 / When to use**: 实验读数的连续指标默认检验（样本量或方差不齐时也成立） / the default readout test for continuous experiment metrics
- **判定 / Decision**: p < α → 两组均值差异显著（方向见均值差） / the group means differ significantly (sign follows the mean difference); otherwise → 未发现显著均值差异 / no significant mean difference
- **参考 / Reference**: Welch, B. L. (1947). The generalization of Student's problem when several different population variances are involved. Biometrika 34(1/2), 28-35.（Welch (1947)）

#### 配对样本 t 检验 / Paired t-test

- **原假设 / H0**: 配对差值均值为 0 / the mean of the paired differences is zero
- **统计量 / Statistic**: `t = d̄ / (s_d/√n),  df = n − 1`
- **前提 / Assumptions**: 配对观测、差值近似正态 / paired observations; differences approximately normal
- **适用 / When to use**: 同一批日期/用户在两个窗口的对比（实际 vs 预期、前后测） / same units observed twice (actual vs expected, before vs after)
- **判定 / Decision**: p < α → 配对差值显著非零：窗口间存在系统性偏移 / the paired difference is systematically non-zero; otherwise → 配对差值不显著：无系统性偏移 / no systematic shift between the paired windows
- **参考 / Reference**: Student (1908), §IX; see also Snedecor & Cochran (1989), Statistical Methods, 8th ed., Ch. 4.（Student (1908)）

#### Wilcoxon 符号秩检验 / Wilcoxon signed-rank test

- **原假设 / H0**: 配对差值的中位数为 0 / the median paired difference is zero
- **统计量 / Statistic**: `W+ = Σ_{d_i>0} rank(|d_i|)，在 H0 下 E[W+]=n(n+1)/4`
- **前提 / Assumptions**: 配对观测；差值分布对称（不要求正态） / paired observations; symmetric differences (normality NOT required)
- **适用 / When to use**: 配对 t 检验的稳健替代，异常值或小样本时使用 / robust alternative to the paired t-test with outliers or small n
- **判定 / Decision**: p < α → 配对差值的中位数显著非零 / the median paired difference is non-zero; otherwise → 未发现中位数偏移 / no median shift detected
- **参考 / Reference**: Wilcoxon, F. (1945). Individual comparisons by ranking methods. Biometrics Bulletin 1(6), 80-83.（Wilcoxon (1945)）

#### Mann-Whitney U 检验 / Mann-Whitney U test

- **原假设 / H0**: 两组来自同一分布（随机抽取一个观测，两组的概率相等） / the two samples come from the same distribution
- **统计量 / Statistic**: `U = R₁ − n₁(n₁+1)/2，标准化后 ~ N(0,1)`
- **前提 / Assumptions**: 独立样本；不要求正态，但要求分布形状相近才能解释为位置差异 / independent samples; no normality, but similar shapes for a pure location reading
- **适用 / When to use**: 重尾金额、评分分布等非正态指标的组间比较 / heavy-tailed or ordinal metrics where t tests are fragile
- **判定 / Decision**: p < α → 两组分布位置存在显著差异 / the two distributions are shifted relative to each other; otherwise → 未发现分布位置差异 / no location shift detected
- **参考 / Reference**: Mann, H. B. & Whitney, D. R. (1947). On a test of whether one of two random variables is stochastically larger than the other. Annals of Mathematical Statistics 18(1), 50-60.（Mann & Whitney (1947)）

#### Kruskal-Wallis H 检验 / Kruskal-Wallis H test

- **原假设 / H0**: 多组来自同一分布 / all groups come from the same distribution
- **统计量 / Statistic**: `H = 12/(N(N+1)) · Σ n_i R̄_i² − 3(N+1) ~ χ²(k−1)`
- **前提 / Assumptions**: 独立样本；各组分布形状相近 / independent samples; similar distribution shapes
- **适用 / When to use**: 多组比较（A/B/n、多分群）的非参数版本 / non-parametric multi-group comparison (A/B/n, many segments)
- **判定 / Decision**: p < α → 至少一组的位置不同（需事后两两比较定位） / at least one group differs (pairwise post-hoc needed to locate it); otherwise → 多组之间未发现差异 / no difference across groups
- **参考 / Reference**: Kruskal, W. H. & Wallis, W. A. (1952). Use of ranks in one-criterion variance analysis. JASA 47(260), 583-621.（Kruskal & Wallis (1952)）

#### 单因素方差分析（F 检验） / One-way ANOVA (F test)

- **原假设 / H0**: 各组均值相等 / all group means are equal
- **统计量 / Statistic**: `F = MSB/MSW = [Σ n_i (ȳ_i − ȳ)²/(k−1)] / [Σ Σ (y_ij − ȳ_i)²/(N−k)]`
- **前提 / Assumptions**: 独立、正态、方差齐性 / independence, normality, equal variances
- **适用 / When to use**: 三组及以上（A/B/n、析因主效应）的整体检验 / omnibus test for three or more arms (A/B/n, factorial main effects)
- **判定 / Decision**: p < α → 至少一组均值不同：先做整体检验再做事后两两比较 / at least one mean differs: follow with pairwise comparisons; otherwise → 各组均值无显著差异 / no significant difference among group means
- **参考 / Reference**: Fisher, R. A. (1925). Statistical Methods for Research Workers. Oliver & Boyd.（Fisher (1925)）


### 比例 · Proportion

#### 两比例 z 检验 / Two-proportion z-test

- **原假设 / H0**: 两组转化率相等（p₁ = p₂） / the two conversion rates are equal
- **统计量 / Statistic**: `z = (p̂₂ − p̂₁) / √(p̂(1−p̂)(1/n₁ + 1/n₂))，p̂ 为合并比例`
- **前提 / Assumptions**: 独立观测；n·p 与 n·(1−p) 均 ≥ 5（稀有事件需精确检验） / independent observations; n·p and n·(1−p) ≥ 5 (rare events need an exact test)
- **适用 / When to use**: CVR / CTR / 留存率等 0-1 指标的实验读数 / experiment readouts on 0/1 metrics such as CVR, CTR, retention
- **判定 / Decision**: p < α → 两组转化率差异显著 / the conversion rates differ significantly; otherwise → 未发现转化率差异 / no difference in conversion rates
- **参考 / Reference**: Kohavi, R., Tang, D. & Xu, Y. (2020). Trustworthy Online Controlled Experiments, Ch. 3. Cambridge University Press.（Kohavi et al. (2020)）

#### 卡方拟合优度检验（SRM） / Chi-square goodness-of-fit (SRM)

- **原假设 / H0**: 实际分流比例等于计划比例 / the realised traffic split equals the planned split
- **统计量 / Statistic**: `χ² = Σ (O_i − E_i)² / E_i ~ χ²(k−1)`
- **前提 / Assumptions**: 各桶独立分配；每桶期望计数 ≥ 5 / independent assignment; expected count ≥ 5 per bucket
- **适用 / When to use**: 读任何实验指标之前的分流健康检查（阈值 0.001） / traffic-health gate before reading any experiment metric (threshold 0.001)
- **判定 / Decision**: p < α → 检出 SRM：分流或日志链路有问题，指标不可信 / SRM detected: randomisation or logging is broken, metrics are untrustworthy; otherwise → 未检出 SRM，可以读指标 / no SRM; metrics can be read
- **参考 / Reference**: Kohavi, R., Tang, D. & Xu, Y. (2020). Trustworthy Online Controlled Experiments, Ch. 4 (SRM).（Kohavi et al. (2020), Ch. 4）

#### 卡方独立性检验 / Chi-square test of independence

- **原假设 / H0**: 两个分类变量独立（如实验分组与转化无关） / the two categorical variables are independent
- **统计量 / Statistic**: `χ² = ΣΣ (O_ij − E_ij)² / E_ij,  df = (r−1)(c−1)`
- **前提 / Assumptions**: 独立观测；期望频数 ≥ 5（2x2 且偏斜时用 Fisher 精确检验） / independent observations; expected counts ≥ 5 (use Fisher for sparse 2x2)
- **适用 / When to use**: 2x2 转化表、父子实验正交性、分组与分群的独立性 / 2x2 conversion tables, parent-child orthogonality, arm vs segment independence
- **判定 / Decision**: p < α → 两变量不独立：分组与结果（或分群）存在关联 / the variables are associated: assignment is related to the outcome (or segment); otherwise → 未发现关联 / no association detected
- **参考 / Reference**: Pearson, K. (1900). On the criterion that a given system of deviations... Philosophical Magazine 50(302), 157-175.（Pearson (1900)）

#### Fisher 精确检验 / Fisher's exact test

- **原假设 / H0**: 2x2 表中两组的比例相等（超几何分布下） / equal proportions in a 2x2 table (hypergeometric null)
- **统计量 / Statistic**: `p = Σ_{t ≥ t_obs} [C(a+b,t) C(c+d, a+c−t)] / C(n, a+c)`
- **前提 / Assumptions**: 独立观测；行列边际固定；无需大样本近似 / independent observations with fixed margins; no large-sample approximation
- **适用 / When to use**: 小样本或稀有事件（转化数很少）的 2x2 比较 / small samples or rare events where the z approximation fails
- **判定 / Decision**: p < α → 两组比例差异显著（精确结论） / the proportions differ (exact conclusion); otherwise → 未发现比例差异 / no difference in proportions
- **参考 / Reference**: Fisher, R. A. (1935). The logic of inductive inference. Journal of the Royal Statistical Society 98(1), 39-82.（Fisher (1935)）

#### McNemar 配对比例检验 / McNemar's paired proportion test

- **原假设 / H0**: 配对二元结果的边际比例相等（b = c） / the marginal proportions are equal for paired binary outcomes
- **统计量 / Statistic**: `χ² = (b − c)² / (b + c) ~ χ²(1)（小样本用精确二项检验）`
- **前提 / Assumptions**: 同一单元两次测量；只使用不一致的配对 (b, c) / same units measured twice; only discordant pairs (b, c) are used
- **适用 / When to use**: 同一批用户前后对比、反转实验的阶段对比 / before/after on the same users, phase comparison in reversal tests
- **判定 / Decision**: p < α → 前后比例显著变化 / the proportion changed significantly between the paired measurements; otherwise → 前后比例无显著变化 / no significant change between paired measurements
- **参考 / Reference**: McNemar, Q. (1947). Note on the sampling error of the difference between correlated proportions. Psychometrika 12(2), 153-157.（McNemar (1947)）


### 分布 · Distribution

#### Kolmogorov-Smirnov 两样本检验 / Two-sample Kolmogorov-Smirnov test

- **原假设 / H0**: 两组来自同一分布（任意形状） / the two samples come from the same distribution (any shape)
- **统计量 / Statistic**: `D = sup_x |F₁(x) − F₂(x)|`
- **前提 / Assumptions**: 独立样本；连续分布（离散数据偏保守） / independent samples; continuous distributions (conservative for discrete data)
- **适用 / When to use**: 检查整条分布是否变化（不只看均值），如金额分布、分数分布 / detecting a shift anywhere in the distribution, not just the mean
- **判定 / Decision**: p < α → 两组分布不同：均值相同也可能分布形状变化，需要看分位数 / the distributions differ: equal means can hide a shape change — inspect quantiles; otherwise → 未发现分布差异 / no distributional difference detected
- **参考 / Reference**: Massey, F. J. (1951). The Kolmogorov-Smirnov test for goodness of fit. JASA 46(253), 68-78.（Massey (1951)）


### 时序 · Time series

#### Ljung-Box 自相关检验 / Ljung-Box autocorrelation test

- **原假设 / H0**: 残差前 m 阶自相关全为 0（白噪声） / the first m residual autocorrelations are zero (white noise)
- **统计量 / Statistic**: `Q = n(n+2) Σ_{k=1..m} r_k²/(n−k) ~ χ²(m)`
- **前提 / Assumptions**: 序列平稳；m 一般取 5–20 或周期长度 / stationary series; m usually 5-20 or one seasonal cycle
- **适用 / When to use**: 时序模型 / ITS 残差诊断：自相关意味着标准误被低估 / residual diagnostics for TS models and ITS: autocorrelation means underestimated SEs
- **判定 / Decision**: p < α → 残差存在自相关：p 值与置信区间偏乐观，需 HAC/ARMA 结构 / residual autocorrelation: p-values and CIs are optimistic — use HAC or an ARMA error term; otherwise → 残差近似白噪声，标准误可信 / residuals are close to white noise; SEs are credible
- **参考 / Reference**: Ljung, G. M. & Box, G. E. P. (1978). On a measure of lack of fit in time series models. Biometrika 65(2), 297-303.（Ljung & Box (1978)）

#### Durbin-Watson 自相关统计量 / Durbin-Watson statistic

- **原假设 / H0**: 残差无一阶自相关（DW = 2） / no first-order residual autocorrelation (DW = 2)
- **统计量 / Statistic**: `DW = Σ (e_t − e_{t−1})² / Σ e_t² ∈ [0, 4]`
- **前提 / Assumptions**: 残差含常数项；按时间顺序排列 / residuals from a model with an intercept, ordered in time
- **适用 / When to use**: 回归残差的一阶自相关快检（DW<1.5 或 >2.5 需警惕） / quick first-order autocorrelation check (flag DW < 1.5 or > 2.5)
- **判定 / Decision**: p < α → 存在一阶自相关：标准误需用 HAC/Newey-West 修正 / first-order autocorrelation present: use HAC/Newey-West standard errors; otherwise → 无一阶自相关 / no first-order autocorrelation
- **参考 / Reference**: Durbin, J. & Watson, G. S. (1951). Testing for serial correlation in least squares regression II. Biometrika 38(1/2), 159-178.（Durbin & Watson (1951)）

#### ADF 单位根检验 / Augmented Dickey-Fuller unit-root test

- **原假设 / H0**: 序列存在单位根（非平稳） / the series has a unit root (non-stationary)
- **统计量 / Statistic**: `Δy_t = α + βt + γ y_{t−1} + Σ δ_i Δy_{t−i} + ε_t，检验 γ = 0`
- **前提 / Assumptions**: 残差无自相关（滞后阶数需足够）；结构性断点会削弱功效 / no residual autocorrelation (enough lags); structural breaks destroy power
- **适用 / When to use**: 建模/ITS 前判断是否需要差分，避免伪回归 / deciding whether to difference before modelling, to avoid spurious regression
- **判定 / Decision**: p < α → 拒绝单位根：序列平稳，可直接建模 / unit root rejected: the series is stationary and can be modelled directly; otherwise → 不能拒绝单位根：先差分/去趋势，或改用带趋势的结构模型 / cannot reject a unit root: difference/de-trend, or model the trend explicitly
- **参考 / Reference**: Dickey, D. A. & Fuller, W. A. (1979). Distribution of the estimators for autoregressive time series with a unit root. JASA 74(366), 427-431.（Dickey & Fuller (1979)）

#### KPSS 平稳性检验 / KPSS stationarity test

- **原假设 / H0**: 序列是（趋势）平稳的 / the series is (trend-)stationary
- **统计量 / Statistic**: `LM = (1/n²) Σ S_t² / σ̂²，S_t 为去趋势后的累积残差`
- **前提 / Assumptions**: 残差无自相关；与 ADF 的原假设相反 / no residual autocorrelation; the null is the opposite of ADF's
- **适用 / When to use**: 与 ADF 互补：两者结论一致时平稳性判断更可靠 / complements ADF: agreement across the two is much stronger evidence
- **判定 / Decision**: p < α → 拒绝平稳：序列含单位根或确定性趋势 / stationarity rejected: the series has a unit root or a deterministic trend; otherwise → 不能拒绝平稳，序列可按平稳处理 / stationarity not rejected
- **参考 / Reference**: Kwiatkowski, D., Phillips, P. C. B., Schmidt, P. & Shin, Y. (1992). Testing the null hypothesis of stationarity. Journal of Econometrics 54(1-3), 159-178.（Kwiatkowski et al. (1992)）


### 回归 · Regression

#### Breusch-Pagan 异方差检验 / Breusch-Pagan heteroskedasticity test

- **原假设 / H0**: 残差方差与解释变量无关（同方差） / residual variance is unrelated to the regressors (homoskedastic)
- **统计量 / Statistic**: `LM = n · R²(e² ~ X) ~ χ²(k−1)`
- **前提 / Assumptions**: 残差独立；线性回归设定 / independent residuals; a linear specification
- **适用 / When to use**: 回归/DiD 的推断前提检查 / inference prerequisite for OLS/DiD
- **判定 / Decision**: p < α → 存在异方差：用稳健（HC1/HC3）或聚类标准误 / heteroskedasticity present: use robust (HC1/HC3) or clustered SEs; otherwise → 同方差假设可接受 / homoskedasticity is acceptable
- **参考 / Reference**: Breusch, T. S. & Pagan, A. R. (1979). A simple test for heteroscedasticity and random coefficient variation. Econometrica 47(5), 1287-1294.（Breusch & Pagan (1979)）

#### 方差膨胀因子（VIF，多重共线性） / Variance inflation factor (multicollinearity)

- **原假设 / H0**: 该变量与其他解释变量不相关（VIF = 1） / the feature is uncorrelated with the other regressors (VIF = 1)
- **统计量 / Statistic**: `VIF_j = 1 / (1 − R_j²)，R_j² 为 x_j 对其余变量的回归 R²`
- **前提 / Assumptions**: 线性模型；数值型特征（类别需先编码） / linear model; numeric features (encode categoricals first)
- **适用 / When to use**: 建模/回归前的共线性体检（VIF > 10 需处理） / pre-modelling collinearity screen (act above VIF 10)
- **判定 / Decision**: p < α → 存在强共线性：系数方向不稳定，用正则化或删/并变量 / strong collinearity: coefficient signs become unstable — regularise or drop/merge features; otherwise → 无明显共线性 / no material collinearity
- **参考 / Reference**: Marquardt, D. W. (1970). Generalized inverses, ridge regression, biased linear estimation, and nonlinear estimation. Technometrics 12(3), 591-612.（Marquardt (1970)）

#### Hosmer-Lemeshow 校准检验 / Hosmer-Lemeshow calibration test

- **原假设 / H0**: 预测概率与 observed 转化率一致（模型校准良好） / predicted probabilities match observed rates (the model is calibrated)
- **统计量 / Statistic**: `χ² = Σ_{g=1..G} (O_g − E_g)² / [E_g(1 − E_g/n_g)] ~ χ²(G−2)`
- **前提 / Assumptions**: 二元结果；按预测概率分 10 组（每组样本足够） / binary outcome; 10 groups by predicted probability with enough units per group
- **适用 / When to use**: 分类模型上线前检查概率是否可直接当转化率使用 / before using predicted probabilities as conversion rates in a decision
- **判定 / Decision**: p < α → 校准不足：排序可能仍可用，但概率不能直接当比率读 / poor calibration: ranking may still work but the probabilities are not rates; otherwise → 校准良好，概率可直接解读 / calibrated; probabilities can be read directly
- **参考 / Reference**: Hosmer, D. W. & Lemesbow, S. (1980). Goodness of fit tests for the multiple logistic regression model. Communications in Statistics A9(10), 1043-1069.（Hosmer & Lemeshow (1980)）

#### Wald 联合 F 检验（前置期系数） / Wald joint F test (pre-period leads)

- **原假设 / H0**: 前置期所有事件研究系数联合为 0（平行趋势成立） / all pre-period event-study coefficients are jointly zero (parallel trends hold)
- **统计量 / Statistic**: `F = [(RSS_r − RSS_u)/q] / [RSS_u/(n−k)]`
- **前提 / Assumptions**: 同一回归设定；聚类稳健协方差 / one specification with cluster-robust covariance
- **适用 / When to use**: DiD 可信度的核心检验：前置期不应已经出现分化 / the core credibility test for DiD: no pre-existing divergence
- **判定 / Decision**: p < α → 平行趋势不成立：DiD 的 ATT 有偏，不能作为因果结论 / parallel trends fail: the ATT is biased and cannot be read as causal; otherwise → 未发现前置期分化，平行趋势可接受 / no pre-trend detected; parallel trends is acceptable
- **参考 / Reference**: Angrist, J. D. & Pischke, J.-S. (2009). Mostly Harmless Econometrics, Ch. 5. Princeton University Press.（Angrist & Pischke (2009), Ch. 5）


### 重抽样 · Resampling

#### 置换检验（随机重排） / Permutation test (label shuffling)

- **原假设 / H0**: 处理标签与结果无关（可交换性） / treatment labels are exchangeable with respect to the outcome
- **统计量 / Statistic**: `p = [#{|T*| ≥ |T_obs|} + 1] / (B + 1)`
- **前提 / Assumptions**: 可交换性（随机分配或随机抽取）；B 越大越精确 / exchangeability from random assignment/sampling; larger B means more precision
- **适用 / When to use**: 交叉验证解析 p 值，分布假设可疑时的首选 / cross-checking analytic p-values, and the default when distributional assumptions are doubtful
- **判定 / Decision**: p < α → 观测差异在重排零分布中罕见：效应不是随机波动 / the observed difference is rare under relabelling: not random noise; otherwise → 观测差异在零分布内常见：不显著 / the observed difference is common under relabelling: not significant
- **参考 / Reference**: Fisher, R. A. (1935). The Design of Experiments. Oliver & Boyd; see also Efron & Tibshirani (1993), An Introduction to the Bootstrap, Ch. 15.（Fisher (1935); Efron & Tibshirani (1993)）

#### Bootstrap 百分位置信区间 / Bootstrap percentile interval

- **原假设 / H0**: （区间估计，不检验单一原假设） / (interval estimate, not a single null)
- **统计量 / Statistic**: `θ̂*_b 由有放回重抽样得到，取 [q_{α/2}, q_{1−α/2}]`
- **前提 / Assumptions**: 重抽样单元必须与随机化单元一致；B ≥ 1000 较稳 / resample the randomisation unit, not the row; B ≥ 1,000 for stability
- **适用 / When to use**: 重尾金额、比率指标、匹配/合成控制的区间估计 / heavy-tailed money metrics, ratio metrics, matching and synthetic-control intervals
- **判定 / Decision**: p < α → 区间不含 0：效应显著（与检验结论互为印证） / interval excludes 0: the effect is significant; otherwise → 区间含 0：方向尚未确定 / interval contains 0: the direction is undetermined
- **参考 / Reference**: Efron, B. (1979). Bootstrap methods: another look at the jackknife. Annals of Statistics 7(1), 1-26.（Efron (1979)）

#### TOST 等效性检验 / Two one-sided tests (TOST) for equivalence

- **原假设 / H0**: 两组差异超出等效界 [−Δ, Δ] / the difference lies outside the equivalence margin [−Δ, Δ]
- **统计量 / Statistic**: `p = max(p_lower, p_upper)，两个单侧 t 检验在 ±Δ 处`
- **前提 / Assumptions**: 需预先声明等效界 Δ；两样本独立近似正态 / a pre-declared margin Δ; approximately normal independent samples
- **适用 / When to use**: A/A 测试、改动“无影响”的证明、护栏指标 / A/A tests, proving a change is neutral, guardrail metrics
- **判定 / Decision**: p < α → 差异落在等效界内：可以认为两组等效（不是“没检出差异”） / the difference is within the margin: the arms are equivalent (not merely undetected); otherwise → 不能宣称等效：样本不足或差异确实超界 / equivalence cannot be claimed: underpowered or genuinely different
- **参考 / Reference**: Schuirmann, D. J. (1987). A comparison of the two one-sided tests procedure and the power approach. Journal of Pharmacokinetics and Biopharmaceutics 15(6), 657-680.（Schuirmann (1987)）


### 多重检验 · Multiplicity

#### Benjamini-Hochberg FDR 校正 / Benjamini-Hochberg FDR control

- **原假设 / H0**: 该指标无效应（对 m 个指标同时检验） / no effect for that metric, across m simultaneous tests
- **统计量 / Statistic**: `p_(i)^adj = min_{j ≥ i} p_(j) · m / j`
- **前提 / Assumptions**: 检验之间正相关或独立；控制 FDR 而非 FWER / independent or positively dependent tests; controls FDR, not FWER
- **适用 / When to use**: 一次读多个指标 / 多个分群时的显著性判定 / declaring significance when reading many metrics or segments at once
- **判定 / Decision**: p < α → 校正后仍显著：可作为上线依据 / still significant after correction: usable for the ship decision; otherwise → 校正后不显著：不要按单个 p 值下结论 / not significant after correction: do not act on the raw p-value
- **参考 / Reference**: Benjamini, Y. & Hochberg, Y. (1995). Controlling the false discovery rate. JRSS B 57(1), 289-300.（Benjamini & Hochberg (1995)）


## 4. Choosing between competing tests

| Situation | First choice | Cross-check | Why |
| --- | --- | --- | --- |
| Two independent arms, continuous metric | Welch t | Mann-Whitney + bootstrap | Welch does not assume equal variances; the rank test survives heavy tails |
| Two independent arms, 0/1 metric | Two-proportion z | Chi-square + Fisher (sparse) | Same estimand, three approximations; agreement is evidence |
| Paired before/after | Paired t | Wilcoxon signed-rank | Pairing removes the between-unit variance |
| Three or more arms | One-way ANOVA | Kruskal-Wallis | Omnibus first, then pairwise with BH |
| Normality of residuals | Shapiro-Wilk (n ≤ 5,000) | Jarque-Bera + Anderson-Darling | Each is sensitive to a different departure |
| Equal variances | Levene / Brown-Forsythe | Bartlett (normal data only) | Levene is robust; Bartlett is more powerful but fragile |
| Stationarity | ADF | KPSS | Opposite nulls; agreement is much stronger than either alone |
| Autocorrelation | Ljung-Box | Durbin-Watson | Ljung-Box covers several lags, DW only the first |
| Heteroskedasticity | Breusch-Pagan | White / HC3 SEs | The fix matters more than the test: use robust SEs |
| Model calibration | Hosmer-Lemeshow | Reliability curve | Ranking can be fine while probabilities are wrong |
| "No difference" claim | TOST | Equivalence bound from the business | A failed test is not evidence of equivalence |
